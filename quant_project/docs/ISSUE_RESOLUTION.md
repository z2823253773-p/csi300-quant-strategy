# 组员一问题清单修订说明

1. 卖出条件：新增 `can_sell_held` 列及宽矩阵，不依赖 `tradable_mask`。它允许已持有股票在出池或变为 ST 后卖出，但停牌、一字跌停、异常行情仍不可卖。该字段只是保守的成交资格，不能保证实际成交。
2. 估值时效：`peTTM`、`pbMRQ` 仅允许最近一次有值的日线观测后 90 个自然日内前填，并导出 `*_age_days`；过期置空。`RUN_METADATA.json` 记录龄期统计。本批缓存二者 p50/p95/max 均为 0，说明日线每天已有数值；不等于财报每天更新。原数据没有公告日，无法验证公告可得时间，正式因子检验应接入公告时间戳后再作严格时点回测。
3. 市值口径：本批 100% 使用 `amount/(turn/100)` 的流通市值估计，没有真实总市值。保留旧列 `ln_mkt_cap` 供兼容，新增 `ln_float_mv_proxy` 明示口径；不能当作总市值解释。建议后续引入带日期的流通股本、总股本与收盘价，计算真实历史市值并做代理误差及模型敏感性检验。
4. 行业口径：缓存路径统一用申万一级分类，去除证监会回填；月度快照超过 45 天失效。重算后未分类比例约 19.63%，行业中性化样本应报告该覆盖率。原始申万变更历史可能事后修订；在取得可靠公告生效日之前，不应声称完全无前视。

本项目仅为组员一的数据工程交接，完整策略回测、收益归因、产品报告和雪球模拟盘仍需全组完成。

## 2026-11-18 开盘接口追加

- 新增 enchmark_open 和 enchmark_intraday_ret，支持首日开盘至收盘的同起点基准比较。原始新浪指数数据包含开盘点位；两指数均已重算。
- 新增 open_quote_observed 长表字段和宽矩阵，仅表示原始日线有正开盘价及昨收价。本批停牌股票日有 2,586 条同样为真，因此它不是开盘可成交标记。is_suspended 含全日成交量与成交额条件，不能作为严格开盘已知字段。
- 组员三须重新核验开盘成交资格、净值与归因；旧版组员二输入哈希以及组员三结果不能套用于本次数据文件。
