# 意见核验与修订总结

## 逐条判断

| 意见 | 核验结论 | 本次处理 |
| --- | --- | --- |
| 新增因子未证明稳定增强 | 支持；新数据重跑仍有同样结论，旧报告本身也已明确不显著 | 保留训练入选表述，披露IC配对检验，不宣称优于基准 |
| Alpha012对价格尺度敏感 | 支持，但不代表公式算错；需要区分价格水平信息和尺度伪差 | 补时间常数单位压力检验及收益率化新方案 |
| Alpha101固定0.001使股票不易比较 | 理论上成立，程度须实测；本批整体排序几乎不变，尾部存在影响 | 同时报数值影响与排序影响，补无固定常数新方案，不夸大缺陷 |
| 50%权重与5日调仓缺乏成本依据 | 作为预设对照合法，但经济合理性不能先验假定 | 完整网格及持仓漂移后换手/成本诊断，主参数不按结果重选 |
| 不反复使用已看过的样本外调参 | 支持 | 区分冻结方案复核与新增探索，不把重用历史区间称新独立验证 |

## 新版数据实际改变了什么

15个原有矩阵数值未变，行业标签133019条由证监会回填改为未分类；新增卖出资格、估值龄期、明确市值代理等字段。全表未分类19.63%，可交易样本未分类21.15%。估值前填时效改动在本批缓存没有改变估值数值。

新增can_sell_held纠正了“出池就不能卖”的接口问题，但不能据此认定可成交或总是保守；它仍使用近似日线阈值。行业统一改善一致性但增加缺失，不能笼统称数据质量问题已全部解决。
