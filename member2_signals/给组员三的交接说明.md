## 1　读哪些数据

- `hs300/signals/target_weights_v3.csv` 和 `zz500/signals/target_weights_v3.csv` 是两套独立账户的目标。分别配组员一新包同名池的 `processed` 和指数 `000300.SH`、`000905.SH`。两个文件有相同的模型名，合并时务必增加股票池标识。每池 8 个模型、185 期、每期 50 股各 2%，共 74,000 行。股票代码按字符串读取。
- CSV 列为 `model, signal_date, execution_date, stock_code, score, target_weight, stage`。第一次信号为 2023-01-06 收盘，第一次执行为 01-09 开盘，之后每 5 个交易日一次。估值持续到 2026-10-30。目标日之间继续持有。CSV 未列出的旧股目标为零，受阻订单和现金由账户引擎处理。stage 按执行日标记。旧入口如只识别 baseline/research，请按 model 分组遍历。
- `signals/factor_*.parquet` 为未经方向翻转的清洗后因子，`score_M*.parquet` 为每日全部可评分股票，`common.parquet` 为新模型共同股票池。各池 `results/model_config_v3.json` 记录输入文件 SHA-256、公式和方向。沪深300 选入 015、中证500 选入 013 和 044，故在原交接清单基础上增加了这些矩阵。净值和实际成交以账户回测为准。

## 3　因子如何选、怎样解释

按各池自己的月度历史成分和当日交易资格，分别执行论文 101 个编号。量以股、金额以元计，价格后复权，adv 采用滚动平均成交金额。池内横截面排名用平均百分位，窗口取整数下整，滚动相关的常数窗口留空；计算前屏蔽缺失报价及停牌。时间窗口可利用入指数前的有效行情。原式涉及不同层级行业或市值时，以申万一级或流通市值代理实现并标记；这些编号保留诊断结果，排除在主选之外。价格尺度、单位和本地算子约定影响外推。公式与算子在 code 目录。[原始论文](https://arxiv.org/abs/1601.00991)

每个交易日在可用股票间截尾（中位数上下 5 倍经调整 MAD，尺度退化时改用 IQR），量价和扩展因子对行业及规模代理作截面回归，取标准化残差；基础三项保留原风格。每个编号独立计算 5 日 Rank IC，标签为 t+1 开盘到 t+6 开盘，两端有有效报价、至少 30 只，剔除跨段和未成熟标签。阶段为训练 2019–2022、验证 2023–2024、已参与讨论的历史后段 2025–2026.10。HAC 使用 Bartlett 权重，5/20 日统计相应使用 5/20 阶，ICIR 为未年化日 IC 均值除以样本标准差。配对 IC 对相同日期和共同有效股票计算。未来标签不参与建仓。

只在训练期选因子。每池分别对 101 次检验作 Holm 校正，无法检验的 p 按 1；保留非代理、训练有效日数至少 600、覆盖率至少 60%、校正 p≤0.05 的候选。按训练平均 IC 绝对值降序，方向由训练期决定；与入选者训练期日均截面秩相关绝对值达到 0.70 就去重，最多取三项。全量结果及每项去留原因见 `alpha101_ic.csv` 和 `selection.csv`。这是池内多重校正，没有校正历次研究中试过的所有设计。

|入选因子|经济含义和观察|
|---|---|
|040（两池）|用近 10 日最高价标准差的截面排名，乘最高价与成交量的负相关项。在两池的训练、验证、历史后段均有正向排序信息，覆盖率高，是最值得优先解释的一项。|
|006、015（沪深300）|006 取开盘价与成交量 10 日相关的相反数；验证期 IC 仅 0.0011。015 衡量最高价排名与成交量排名的短期联动，取三日相关的截面排名、再作三日负和。连续短窗需有可定义的相关系数，验证期覆盖仅 52.4%。016 的训练 IC 为 0.01602，略低于 015 的 0.01621，因三席已满落选。|
|013、044（中证500）|013 对收盘价排名与成交量排名的五日协方差取负排名；044 取最高价与成交量截面排名的五日相关的相反数。两者均奖励较弱的价量联动，不宜将它们解释成完全独立的风险来源。|

补充的 `price_scale_check.csv` 将原 012 的绝对价差替换为相对收益，将原 101 改为 `(C/O−1)/((H−L)/O+0.001)`，并与原公式对照。两项替代式仅作稳健性检验。012 相对价差版与 M3b 的成交额平滑版是两个不同实验。5 日和 20 日的扩展因子、相关性与配对结果均放在各池 results 目录。

## 5　复现

使用 Python 3.12，本次环境为 numpy 2.5.5、pandas 3.1.1、pyarrow 26.0.1、matplotlib 3.11.2。解压组员一数据，将下面的 DATA 换成其中 tushare_data 的路径，在本交接包根目录运行。程序使用本地 processed 文件，无需获取行情。每池使用独立临时目录缓存 101 项中间结果，运行完释放。

```powershell
foreach ($pool in 'hs300','zz500') {
    python code/run_pool.py --data "DATA/$pool/processed" --out $pool
    python code/price_scale.py --data "DATA/$pool/processed" --out $pool
}
python code/report.py
python code/check_015.py
```

验收包括两池各 101 个编号与三个统计阶段、入选原始公式的截短历史对照、共同池一致、信号到次一交易日执行、权重和与唯一键、每期按分数及缓冲独立复选、原 012/101 的诊断结果与主检验对账。2026-10-30 之后的行情未包含在本交接包中。
